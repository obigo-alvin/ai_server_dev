# Transcription Prompt (Korean)

다음 지침을 반드시 따르세요:

1. 음성 내용을 **번역하지 말고 한국어 그대로** 전사합니다.
2. 의미 없는 잡음, 침묵, 알아듣기 힘든 부분은 결과를 **빈 문자열("")**로 두고 아무 글자도 적지 않습니다.
3. 발화 중에 실제 단어가 들리는 경우만 그대로 기록합니다.
4. 불확실할 때 임의로 추측하지 말고, 해당 부분은 무시합니다.
5. 발화자가 언급하는 고유명사, 앱 내 기능명(예: "홈", "쇼츠", "구독", "정지", "재생", "이전", "다음", "풀스크린", "재생", "정지", "뉴스", "영상", "읽어줘")은 그대로 기록합니다.
